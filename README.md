# Stremera - Android Live Streaming & Screen Cast App 📱

Stremera is a high-performance open-source Android application built for real-time mobile screen broadcasting, camera live streaming, sports scoreboard overlays (Cricket & Football), and dynamic banners.

Download the latest official ready-to-install APK directly from GitHub:

---

### 🚀 Key Features
- 📺 **Screen Casting**: Broadcast your screen with audio using Android's MediaProjection API.
- 🎥 **Live Camera Streaming**: Stream live with front/back camera and local video recording.
- 🏏 **Live Sports Scoreboards**: Real-time floating scoreboard overlays for Cricket & Football.
- 🎨 **Dynamic Overlay Banners**: Manage custom live banners and overlays.
- 🫧 **Floating Controls**: Floating bubble widget to easily manage streaming over any app or game.
